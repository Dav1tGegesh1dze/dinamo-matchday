Desktop builds of the Dinamo Tbilisi stand game. No developer tools needed: download, open, play.
Everything runs offline and results are stored on the machine itself.

## Download

| Platform | File | How to run |
|----------|------|------------|
| Windows 10/11 | `Dinamo Road to Goal-0.1.0-setup.exe` | Run the installer. If SmartScreen appears: **More info → Run anyway**. |
| Windows (no install) | `Dinamo Road to Goal-0.1.0-win.zip` | Unzip anywhere, double-click `Dinamo Road to Goal.exe`. |
| Mac (M1/M2/M3/M4) | `Dinamo Road to Goal-0.1.0-arm64.dmg` | Open, drag to Applications. First launch: **right-click → Open** (the app is not notarised). |
| Mac (Intel) | `Dinamo Road to Goal-0.1.0.dmg` | Same as above. |

The `-mac.zip` files contain the same app as the matching `.dmg`.

## Playing

Register with a name, mobile number and e-mail. Find your kit in the dressing room and the tape in
Physio, then reach the coach in the tunnel. Answer four questions to score. **Play again** on the
result screen starts a new run for the same player.

## For the club

On the result screen: `Ctrl+Shift+E` downloads every attempt as JSON, including the players' phone
numbers and e-mail addresses, so winners can be contacted. `Ctrl+Shift+X` clears the leaderboard.
On a touchscreen, tap the headline five times for the same two buttons. Please reset the board
after the event, since the contact details live only on that machine.

Quit with `Alt+F4` (Windows) or `Cmd+Q` (Mac).
